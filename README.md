# DSA Learning Portal

A local learning portal for DSA interns with:

- Intern login and progress tracking
- Admin-only controls
- Loom video lessons synced from the Excel video sheet
- Per-video resources and file uploads
- AI Assistant Yash link

## Run Locally

Double-click:

```text
Start DSA Learning Portal.bat
```

Then open:

```text
http://127.0.0.1:5173
```
